# VRP & TSP Optimization (Python + Gurobi)

This repository contains **Vehicle Routing Problem (VRP)** and **Traveling Salesman Problem (TSP)** optimization models implemented in **Python** using **Gurobi**.

## Objective
Minimize total travel distance (or total routing cost) and generate efficient routes.

## What’s inside
- Python scripts/notebooks for VRP and TSP models
- Input data files (e.g., coordinates or distance matrix)
- Output / results examples (routes, objective value)

## Tools & Technologies
- Python
- Gurobi Optimizer

## Notes
These models were developed as part of academic and personal studies in operations research and logistics optimization.
